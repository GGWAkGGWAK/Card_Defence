## 이번 점검에서 보강한 항목

- 투사체가 목표에 도착한 시점에 피격 이펙트와 데미지 숫자가 표시되도록 타격 타이밍 통일
- 제한시간 직전 보스가 치명타를 받은 경우 사망 애니메이션 중 실패로 오판하지 않도록 보호
- 카드 길게 누르기 상세 정보: 카드명, 족보, 공격력, DPS, 사거리, 전투 특성
- 5장 선택 시 합성 결과의 족보, 대표 카드, 기본 공격력, 핵심 재료 수 미리보기
- 배치·드래그 중 빈 슬롯은 초록색, 교환 가능한 점유 슬롯은 주황색으로 표시
- Android 뒤로가기: 창 닫기, 튜토리얼 닫기, 상호작용 취소, 2회 입력 저장 종료
- 앱 일시정지뿐 아니라 포커스 상실 시에도 현재 진행 자동 저장

## 100% 출시 후보까지 남은 작업

1. 실제 Android 기기 3종 이상에서 해상도, 발열, 배터리, 백그라운드 복귀를 30분 이상 확인
2. 1·10·20·30·50라운드 실플레이 로그를 수집해 골드와 처치시간의 최종 수치 조정
3. 앱 아이콘, 스플래시, 스토어 스크린샷, 개인정보처리방침 및 배포 서명 구성
4. 최종 BGM·효과음의 저작권 및 이어폰·스피커 음량 기준 확인
5. 치명적 오류 수집, 기기별 그래픽 품질 기본값, QA 체크리스트를 거친 출시 후보 고정
