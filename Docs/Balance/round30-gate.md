# 30라운드 첫 난관 밸런스 (2026-09-05)

목표: 낮은 족보 위주로 성장한 경우 30라운드 보스가 여러 웨이브에 걸쳐 잔류하고, 보스 대응 족보를 확보한 경우 돌파 여지를 만든다.

## 적용 규칙

- 정규 보스 체력: 해당 라운드 기본 몬스터 체력의 10배(R10), 30배(R20), 80배(R30 이후).
- 일반 웨이브 체력: R11부터 라운드마다 기본 곡선 대비 2.5%p 추가, R30에서 50% 추가에 도달해 유지.
- 처치 골드 성장: R20까지 기존 2.2%, 이후 1.2%. 보스 강화에 비례한 추가 골드는 지급하지 않는다.
- 합성 재료 기여도, 소환 점유 비용, 강화 비용·공격력 증가율은 직전 버전을 따른다.
- 퀘스트 보스는 정규 보스 배율의 적용 대상이 아니다.
- 이미 저장된 몬스터의 체력은 보존된다. 비교 플레이는 새 게임으로 진행한다.

## 전투력 비교 조건과 한계

30라운드 보스 HP 약 37,977. 동일한 7 카드 중심 족보 4기, 해당 족보 강화 6레벨, 공격 가동률 65%를 가정한다. 실제 합성 재료의 공격력과 족보 보스 추가 피해를 사용한다. 원페어는 7♠,7♥,2♦,5♣,9♠이고 트리플은 2♦ 대신 7♦이다.

- 원페어 4기: 보스 집중 공격에 약 65.6초. 20초 웨이브가 3회 이상 이어져 다른 몬스터 처리에도 부담이 생긴다.
- 트리플 4기: 약 17.9초. 보스 대응 구성이면 한 웨이브 내 처치할 여지가 있다.

양쪽 모두 최소 20장 소환과 4회 합성이 필요하다. 이 비교는 원하는 재료를 뽑는 데 드는 재소환 비용, 카드 획득 확률, 경로별 사거리, 일반 몬스터에 분산되는 공격, 성장 선택과 퀘스트 보상을 모델링하지 않는다. 따라서 실제 클리어 확률이나 30라운드 강제 패배를 의미하지 않는다. 기존 EndlessBalanceSimulator는 잠재 골드 예산 참고용이며 실제 덱 구성·몬스터 누적 시뮬레이션이 아니다.

## 검증

EditMode에서 보스 차등 체력, 보상 유지, 약한 원페어 구성의 2웨이브 초과 처치시간과 트리플 구성의 1웨이브 이내 처치시간을 검사한다. PlayMode에서 30라운드를 실제 생성해 보스 체력이 보고용 계산과 일치하는지 검사한다. 체감 난이도는 Android 및 PC 새 게임 플레이로 추가 확인해야 한다.
