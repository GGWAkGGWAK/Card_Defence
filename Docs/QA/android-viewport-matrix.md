# Android 화면 비율 QA 매트릭스

기준: Unity 2022.3.19f1, 세로 플레이, 보스 외곽 여백 1.05 월드 단위

| 화면 유형 | 테스트 비율 | 경로 처리 | 카메라 처리 | 자동 검증 |
|---|---:|---|---|---|
| 일반 Android | 9:16 | 약 82.6% 축소 | 기본 7.3 유지 | 통과 |
| 최신 Android | 9:19.5 | 82% 하한 유지 | 약 8.85로 확장 | 통과 |
| 긴 Android | 9:20 | 82% 하한 유지 | 약 9.08로 확장 | 통과 |
| 태블릿 | 3:4 | 원래 크기 유지 | 기본 7.3 유지 | 통과 |
| PC | 16:9 | 원래 크기 유지 | 기본 7.3 유지 | 통과 |

## 자동 검증 항목

- 몬스터 경로 64개 표본 좌표와 보스 여백이 카메라 범위 안에 존재
- 외곽 카드 슬롯과 보스 경로 중심 간 최소 1.28 월드 단위 확보
- 화면 비율 변경 후 이미 배치된 카드가 변경된 슬롯 중심으로 이동
- 배경 스프라이트가 카메라 가로·세로 범위를 모두 덮음
- 화면이 넓어지면 카메라 크기와 경로 크기가 기본값으로 복구
- 경로선과 실제 몬스터 이동 좌표가 동일한 캐시를 사용

## 실제 기기 확인 항목

- 노치와 펀치홀 영역이 골드·라운드·배속 UI를 가리지 않는지 확인
- 시스템 내비게이션 바 표시 상태에서 하단 버튼이 잘리지 않는지 확인
- 30라운드 보스가 외곽 카드 및 체력바와 시각적으로 겹치지 않는지 확인
- 앱을 가로 방향으로 돌렸다가 세로로 복귀했을 때 카드와 몬스터 위치 확인
- 백그라운드 전환 후 화면, BGM, 게임 속도, 저장 상태 확인
- 저사양 기기에서 몬스터가 많이 쌓였을 때 30 FPS 이상 유지 확인

실제 기기 항목은 APK 설치 후 사람이 확인해야 하며, 자동 테스트 통과만으로 완료 처리하지 않는다.
